# نقل المحتوى والصور في الإصدار 2.0.0-cloudflare.2

المحتوى الحالي موجود بالفعل داخل deployment-data: 37 سجل منتج، منها 35 ظاهرًا، و6 أقسام و12 سؤالًا وجوابًا وسجلّا منشور، و12 صورة مرفوعة كاملة. توجد 0 مراجعة في قاعدة Sites وقت التصدير. الصور الأصلية ضمن public/assets. لا يحتاج المالك إعادة إدخال هذا المحتوى أو رفع الصور يدويًا.

## الاستخدام المعتاد

بعد إنشاء D1 وR2 مستقلتين وضبط الرابط وAccess وبريد المالك، نفذ npm run deploy من مجلد النسخة. سيطبق الترحيلات ثم:

1. يتحقق من بصمة اللقطة وكل صورة وحجمها قبل رفع أي ملف.
2. يرفض قاعدة تحتوي بيانات بلا علامة استيراد سابقة؛ لا يمسح البيانات الموجودة.
3. يرفع الصور إلى abu-mustafa-cloudflare-photos ويستورد الجداول إلى القاعدة الفارغة.
4. يراجع عدد المنتجات والصور والعلاقات، ثم ينشر Worker.
5. في النشر التالي، يتعرف على علامة cloudflare_import_v1 ويحافظ على تعديلات الموقع الحالية دون استبدالها باللقطة القديمة.

اضبط أمر النشر في ربط GitHub بـ Cloudflare على npm run deploy. أمر npx wrangler deploy وحده يتخطى استيراد البيانات والصور.

## النسخة الاحتياطية الكاملة الخاصة

حُفظت نسخة كاملة على جهاز المالك في E:/abu-mustafa-website/cloudflare-live-snapshot-2026-10-08. تشمل جداول التطبيق العشرة وسجل الإدارة وعضو الفريق وجميع الصور الـ12. هذه السجلات الخاصة لا تدخل ملفات الموقع العامة أو حزمة المحتوى التجاري في GitHub.

إذا أُريدت استعادة سجل الإدارة والفريق أيضًا، استخدم النسخة الخاصة بدل deployment-data قبل أول نشر على قاعدة فارغة:

~~~sh
npm run db:migrate:remote
npm run data:restore -- --source ABSOLUTE_PRIVATE_BACKUP_DIRECTORY
npm run deploy
~~~

أداة الاستعادة تضبط علامة الاستيراد أيضًا. تزيل ربط المالك بهوية Sites وتعيد user_id لأعضاء الفريق إلى NULL ليتم ربطهم بهويات Cloudflare Access عند دخولهم. الأدوار والسجل والمحتوى يبقون محفوظين. يحتاج بريد عضو الفريق إلى سماح مستقل في سياسة Access.

يمكن تجهيز SQL وخطة رفع الصور محليًا دون الاتصال بموارد Cloudflare:

~~~sh
npm run data:restore -- --prepare-only
~~~

تولّد هذه الخطوة ملفات مؤقتة تحت .wrangler؛ لا ترفعها إلى GitHub. لا يحتوي المصدر أسرار الاستضافة. عند تعطل استيراد جزئي، أوقف المحاولة واحتفظ بالقاعدة للتشخيص واستعمل قاعدة جديدة؛ لا تحاول إزالة الحاجز أو مسح البيانات.

الاستضافتان مستقلتان: تحديث محتوى Sites بعد التصدير لا يظهر في Cloudflare تلقائيًا، والعكس صحيح. التشغيل الفعلي على حساب Cloudflare يحتاج إعداد موارد الحساب وتسجيل الدخول ثم اختبار الرابط الحقيقي.
