فحوص Access تشمل التوقيع الصحيح والخاطئ، الجمهور والمرسل، انتهاء المدة، هوية الخدمة، البريد المفقود، ترويسات Sites المزيفة، ومجال مفاتيح غير مسموح. تحققت تجربة التشغيل من المالك والمحرر وسحب صلاحياته ومنع التعديل عبر مصدر خارجي وإخفاء المسودة. مفاتيح التجربة محلية مؤقتة ولا تدخل مدخل الإنتاج.

تجربة الاستيراد استرجعت 35 منتجًا إلى D1 جديدة بلا علاقات مكسورة، وحافظت على العربية والاقتباسات والأسطر، ورفضت قاعدة تحتوي بيانات سابقة. تحققت أيضًا بصمات قاعدة وصورة تجريبية، ورفضت صورة تالفة ومجلد إخراج موجودًا.

المتصفح المحلي: إطارات بعرض 360 و390 و768 بكسل. العرض الداخلي مع شريط التمرير 345 و375 و753، وscrollWidth يساويه في الأحجام الثلاثة. لم تظهر صور مكسورة في العناصر الظاهرة. عمل البحث عن «لافيرن»، ولم تسجل معاينة المتجر أخطاء JavaScript أو تحذيرات وقت الفحص. أظهر دخول الإدارة المباشر رسالة الحماية دون جلسة دخول. هذه معاينة متصفح، وليست اختبار هاتف فعلي جديد أو تجربة Access في الحساب السحابي.

حافظت النسخة على الروابط التاريخية الـ11 كصفحات أرشيف غير مفهرسة؛ لم تسمح لصفحات HTML قديمة بحجب المنتجات الحالية. بقي الفرع main وموقع Sites المنشور خارج التعديل.

## ما يحتاج التحقق عند إعداد الحساب

- إنشاء D1 وR2 الفعليتين، وتطبيق الترحيلات على قاعدة جديدة.
- سياسة Access ومساراتها على رابط workers.dev الفعلي أو النطاق المعتمد، ووسيلة تسجيل دخول المالك وSecret بريده.
- تشغيل npm run deploy لاستيراد حزمة المحتوى الحالية والصور أول مرة، أو استيراد النسخة الخاصة الكاملة قبل أول نشر إذا أُريد سجل الإدارة والفريق.
- فحص الرابط الحقيقي من الهاتف والكمبيوتر، واختبار رفع الصور واستمرار البيانات ومراقبة حدود الحساب.
- اعتماد الرابط النهائي والفهرسة وملكية Search Console.

عدم وجود ثغرات اعتماديات معروفة واجتياز الاختبارات لا يعني تدقيقًا أمنيًا شاملًا أو ضمانًا مطلقًا بعدم وجود أخطاء.

## اكتمال نسخة المحتوى الحالية

وصل تصدير القراءة فقط من Sites إلى نهاية جميع صفحات الجداول العشرة دون أعمدة أو قيم مبتورة. يحتوي المصدر على 37 سجل منتج، منها 35 ظاهرًا، و6 أقسام و12 سؤالًا وجوابًا وسجلّي منشور و12 صورة مرفوعة، مجموعها 973440 بايتًا. قاعدة Sites الحالية لا تحتوي تقييمات.

اجتازت الاستعادة المحلية 116 فحصًا: تطابق جداول المحتوى التجاري، وتطابق بصمات الصور الـ12 بايتًا ببايت، وعمل المنتجات الـ35 والصور الـ47 المستخدمة فيها والمنشور الظاهر، وعدم وجود علاقات مكسورة، ورفض إعادة الاستيراد إلى قاعدة ممتلئة، ومنع دخول الإدارة بلا Access.

بالإضافة إلى ذلك نجحت مقارنة الكتالوج الحي مع النسخة المستعادة بعد تحويل رابط الاستضافة فقط: المنتجات والأقسام والأسئلة والمنشورات متطابقة. فحص المقارنة الكامل يعرض 121 تحققًا (116 محليًا و5 للمصدر الحي). لم تُكتب أي بيانات إلى Sites أو Cloudflare أثناء هذه الاختبارات.

النسخة الخاصة الكاملة على جهاز المالك تحفظ أيضًا عضو الفريق وسجلات الإدارة الـ16. نسخة GitHub تحمل المحتوى والصور وتبدأ هوية إدارة جديدة على Cloudflare. حساب Access الحقيقي والنشر في حساب المالك ورفع صورة جديدة إلى R2 السحابية ما زالت تحتاج تجربة هناك.
