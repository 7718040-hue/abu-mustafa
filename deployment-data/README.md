# لقطة محتوى الموقع الحالية

هذه الملفات جزء من مصدر الإصدار 2.0.0-cloudflare.2. تتضمن المنتجات والأقسام والأسئلة والمنشورات والصور المرفوعة كما كانت في موقع Sites عند التصدير يوم 8 أكتوبر 2026.

database.json هو لقطة الجداول للمحتوى التجاري، وmanifest.json يثبت بصمتها وبصمات الصور، وobjects يحتوي 12 صورة كاملة دون إعادة ضغط. الصور الأصلية موجودة أيضًا في public/assets.

أمر npm run deploy يستوردها مرة واحدة إلى قاعدة وحاوية Cloudflare مستقلتين قبل نشر Worker. لا تُنسخ هذه الملفات إلى dist/client ولا تصبح قاعدة البيانات ملفًا عامًا. لا تغير اللقطة أو بصماتها يدويًا. إعادة النشر تحافظ على تعديلات لوحة الإدارة الحالية.

هوية مالك Sites وأعضاء فريقه وسجلهم الخاص محفوظة في النسخة الاحتياطية الخاصة على جهاز المالك. يُضبط الدخول والمالك والفريق في Cloudflare Access ولوحة الموقع الجديدة. توجد 0 مراجعة في المصدر وقت التصدير.
