# مركز أبو مصطفى — نسخة Cloudflare المستقلة

نسخة 2.0.0-cloudflare.1، مبنية من آخر مصدر مُراجع لنسخة Sites بتاريخ 8 أكتوبر 2026. محفوظة في فرع cloudflare-hosting؛ الفرع main مخصص لنسخة Sites الحالية.

استضافة هذه النسخة: **Cloudflare Workers + D1 + R2 + Access**. الموقع العربي ولوحة الإدارة والتعليمات والمنتجات والصور الأولية محفوظة. لا يوجد نشر تلقائي عند تنزيل المصدر.

ابدأ بـ[دليل الإعداد الكامل](docs/cloudflare-setup.md)، ثم [دليل نقل البيانات والصور](docs/cloudflare-transfer.md).

~~~sh
npm ci
npm test
npm run build
~~~

يتطلب Node 22.13 أو أحدث. املأ إعدادات الرابط المستقل وD1 وAccess في wrangler.json، واضبط SITE_OWNER_EMAIL في حساب Cloudflare كسر. npm run deploy:check يرفض الإعدادات النموذجية؛ npm run deploy ينشر فقط عندما تنفذه بعد إعداد الحساب.

مجلد dist ناتج بناء غير محفوظ في Git، ومجلد .openai غير مستخدم. المصادقة الحقيقية من Cloudflare Access. الملف worker/index.mjs يمثل منطق التطبيق الداخلي، ومدخل الإنتاج worker/cloudflare.mjs يزيل هوية Sites غير الموثوقة ويتحقق من JWT قبل وصول الإدارة إلى البيانات.

البيانات المحفوظة في Sites والصور المرفوعة إلى R2 ليست داخل GitHub. هذه النسخة تبدأ بـ35 منتجًا أوليًا، ما لم تستورد لقطة كاملة من البيانات الحالية قبل فتحها. لا تستخدم نسخة محلية تحتوي تقييمات تجريبية كبيانات المحل.

انظر [نتيجة الفحص](docs/cloudflare-validation.md) لمعرفة ما تحقق محليًا وما يحتاج تجربة في حساب Cloudflare.
