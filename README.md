# مركز أبو مصطفى — نسخة Cloudflare المستقلة

الإصدار 2.0.0-cloudflare.2 يحفظ محتوى موقع Sites الحالي كما جرى تصديره في 8 أكتوبر 2026، مع الصور الأصلية و12 صورة مرفوعة من لوحة التحكم. الاستضافة Cloudflare Workers + D1 + R2 + Access.

الفرع cloudflare-hosting مستقل عن main. موقع Sites يظل يعمل برابطه وبياناته. بعد النسخ، التعديلات الجديدة في إحدى الاستضافتين لا تنتقل إلى الأخرى تلقائيًا.

## المحتوى المضمن

- 37 سجل منتج، منها 35 ظاهرًا، مع الأوصاف والأسعار والتوفر والترتيب والبطاقات الحالية.
- 6 أقسام، و12 سؤالًا وجوابًا، وسجلّا منشور، أحدهما منشور ظاهر والآخر محذوف.
- الصور الأصلية في public، و12 ملفًا مرفوعًا في deployment-data/objects مع بصماتها.
- لا توجد تقييمات في قاعدة Sites وقت التصدير؛ لا تُضاف آراء افتراضية أو تقييمات التجربة المحلية.
- لوحة التحكم وتعليماتها والصلاحيات ورفع الصور تعمل بمنطق التطبيق نفسه، مع تسجيل الدخول عبر Cloudflare Access.

السجلات الخاصة بهويات الإدارة وتاريخها محفوظة في نسخة احتياطية كاملة خاصة على جهاز المالك. لا تدخل في ملفات الموقع العامة. يُضبط المالك والفريق في حساب Cloudflare الجديد.

## التشغيل

يتطلب Node 22.13 أو أحدث. ابدأ بـ[دليل الإعداد العربي](docs/cloudflare-setup.md)، واضبط الرابط وموارد D1 وR2 وAccess وبريد المالك.

~~~sh
npm ci
npm test
npm run deploy:check
npm run deploy
~~~

أمر npm run deploy يطبق ترحيلات القاعدة الجديدة، ويتحقق من ملفات النسخة، ويرفع الصور إلى R2، ويستورد المحتوى إلى D1 الفارغة، ثم ينشر Worker. عند النشر التالي يحافظ على البيانات الحالية ولا يعيد استبدالها باللقطة القديمة. لا تستخدم أمر النشر الافتراضي npx wrangler deploy قبل الاستيراد.

النسخة لا تتصل باستضافة Sites لجلب صورها عند التشغيل. لم تُنشر داخل حساب Cloudflare بعد؛ يحتاج الدخول والرابط الحقيقي إلى اختبار بعد إعداد الحساب. راجع [نتائج التحقق](docs/cloudflare-validation.md).
